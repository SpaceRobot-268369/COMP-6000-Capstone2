# Layer C top8 retrieval event library

Unified retrieval index for the Layer C MVP retrieval baseline. The library combines audited real snippets for Horsfield's Bronze-cuckoo and Splendid Fairywren with the later human-calibrated top35 libraries for six additional bird species.

The runtime index is `layer_c_retrieval_top8_event_index.csv`. Audio and review assets are DVC-tracked in the source library directories referenced by each row.

This is a retrieval baseline: output events are real audited snippets, not from-scratch generated bird calls.
