# SA3 LoRA Core6 Dataset

Derived from stable_audio_core_reference_bank_pass6.csv. Each WAV is a symlink to a real audited Horsfield's bronze cuckoo crop, with a matching text caption for official Stable Audio 3 LoRA training.

Caption: clean Horsfield's bronze cuckoo bird call, repeated descending whistled notes, clear foreground call, sparse natural woodland background, short isolated bird vocalisation
