`resources/site_257_bowra-dry-a/bird_audio_annotation_inventory_other_tags.csv`

## Selection Summary

- Use the first 63 species from the inventory CSV.
- Include the eight species used by prior Layer C retrieval work.
- Reuse prior human-pass samples only after revalidating and repackaging them
  under the v2 crop, bandpass, metadata, and review rules.
- Fill species shortfalls from local annotations first, then S3-backed source
  audio.
- Per-species target count is derived from `local_annotation_audio_count`.

## Required Per-Species Layout

```text

    <NNN>_audioevent_<audio_event_id>/
      original.wav
      crop_full.wav
      crop_bandpass.wav
      mel_full.png
      mel_bandpass.png
      metadata.json
      review.json
```

The final retrieval index should use `crop_bandpass.wav` and include only
samples with a v2 `Pass` review verdict.
